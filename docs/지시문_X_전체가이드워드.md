## X-G7 측정 사전 등록 (측정 전에 커밋)

- 입력: 부스 칩 "아파트 LPG 공급" 문장(절차 키워드 없음 → 표준 7종). 같은 입력으로 병렬 4·7 각 1회, 이어서 채택한 병렬 수로 2회 더(합 3회).
- 판정 규칙: 병렬 7 이 **429 재시도 0회이고 총 시간이 병렬 4 보다 15% 이상 짧으면** 7 채택, 아니면 4 유지. 1회 비교라 15% 미만 차이는 잡음으로 본다.
- 기록: `results/xg7_<시각>/` 에 회차별 지연·비용·판정 셀·429 횟수·첫 가이드워드 완료 시각. README §6·화면 문구는 3회 범위(최소~최대)로.
