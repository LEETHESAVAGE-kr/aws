# 지시문 V — 부스 모드 (본선 PRD F-04, FR-10)

작성 2026-10-08 · 상위 `docs/PRD_본선_고도화.md` F-04 · UI(FR-10)는 spec 대신 지시문으로 관리해 온 관례(H·J·M·U)를 따른다.
공급자: 사용자 결정(10/8)으로 **본선 동안은 기존 Anthropic API**, 대회 키는 마지막에 전환(F-01 보류).

## 비목표 (이번에 안 함)

- **생성 중 버튼 잠금(쿨다운)**: Streamlit 은 생성 중 다른 버튼을 누르면 실행을 끊고 다시 그린다 — 이미 화면에 "다른 버튼을 누르면 취소" 안내가 있다. 잠그려면 실행 상태를 세션 밖에 둬야 해서 크다. 현장 운영(옆에서 설명)으로 대신한다.
- 사고 사례 카드 순환: R-11 단계 표시가 대기 시간을 채운다.
- QR 코드: 앱이 아니라 출력물로 만든다(새 의존성 불필요). 투표 유도 문구는 운영사 확인 뒤(PRD Q4).

## 알려진 한계

- `?booth=1` 은 공개 URL 에서 누구나 붙일 수 있다. 세션 상한은 원래 새로고침으로 우회되므로 새 위험은 아니다 — 실질 비용 상한은 일 상한이다.
- 일 상한은 프로세스 메모리 카운터라 재시작하면 0 으로 돌아간다(README §7). 부스 당일 예산 = 일 상한 × 약 $0.14(10/8 실측 $0.138).
- 운영: 10/20 아침 Secrets `HAZOP_DAILY_LIMIT` 를 부스 예산에 맞춰 올리고(예: 60 → 약 $8.3), 끝나면 되돌린다.
