## Y-2 평가기준 다변화 (P0) — 완료 10/9

원문 조사(10/9): **KOSHA GUIDE P-82·P-86 은 2026-01-30 폐지**, 후속은 기술지원규정 C-C-37-2026(연속)·C-C-41-2026(회분) — 위험도 표는 넷 다 같다. 고용노동부고시 제2024-76호는 등급표가 없다(사업장이 정함). 사용자 결정(10/9): **C-C-37 을 그 단계 그대로**(S 4 · F 3 · 대조표 1~5), 기준은 많을수록 좋다 → 라이브러리 3종.

| # | 구현 | 시험 |
|---|---|---|
| Y-2a | `core/criteria.py` + `data/kb/criteria/` 3종: `kosha_cc37_2026`(기본, 대조표), `moel_guide_3x3_2023`(곱, 안내 비교용), `nh3_sts_bunkering`(골드셋 파일을 가리킴). 출처·쪽·이용 조건은 파일과 `data/README.md` | `tests/test_criteria.py` — 원문 <표 2> 대조, 수식=코드 값, 출처 필드 |

| Y-2c | 선택: 직접 입력(`run_live`·`run_quick`) → C-C-37, 그 밖(재생·골드셋) → 레코드의 기준(없으면 NH3 — 10/9 이전 캡처는 NH3 로 생성됐다) | AppTest 배지 |

| Y-2e | 화면: 배지 "〈기준〉 기준으로 매겼습니다(위치)", 검토 S·F 범위·머리글, 안내 탭 기준 3종 전환(등급·대조표·구간·주의), 폐지된 "P-82" 문구 → C-C-37 | AppTest |

**남은 것**: 직접 입력 실호출 1회로 C-C-37 등급 분포 확인(Y-G5 재측정에 포함). 재생 P1·P2·I1~I4 는 NH3 기준 캡처라 '참고용' 배지 유지 — 재캡처하면 C-C-37 로 바뀐다.
