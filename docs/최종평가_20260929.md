- **본선 진출 45~55% → 50~60%.** 1차 N 의 "지금 40~50%" 에서 올린 이유: README 빈칸 0, 트리 clean·push 완료로 "미완 제출" 위험이 사라졌고, 예시 공정 품질(P-1)과 지연이 실제로 좋아졌다. "실행 후" 를 1차 N 과 같게 둔 이유: Bedrock 설명 삭제가 SA 한 명의 점수를 깎는 폭이 그 개선분과 비슷하다. 25~40팀 중 8~10팀 진출이라면 52~54점은 경계선 위로 보이지만 근거는 심사표 해석뿐이다. **근거 약함.**
