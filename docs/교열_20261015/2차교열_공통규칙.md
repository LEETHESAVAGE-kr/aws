## 바꾸지 않은 것

- 생성 프롬프트(가이드워드 정의 `GUIDEWORD_DEFINITIONS` 포함) — 바꾸면 새 생성 결과와 측정값이 달라진다. 화면의 가이드워드 뜻만 `guide.GUIDEWORD_MEANINGS`로 따로 둔다.
- Excel 머리글 '기존 안전장치(Before)' — 원본 워크시트 양식 12열 문자열 그대로(R-02). 화면 머리글만 바꿨다.
- 공식 기준표(KOSHA·고용노동부)와 팀 기준표 문구, 정보 4단계 표(프롬프트와 같은 문구), 예시 공정 문장(해석 응답 녹화의 열쇠).
- 화학식 괄호(잔사(NCl3)), 사실관계가 틀려 보이는 곳(교열 범위 밖).
- 저장된 재생 JSON — 1차와 같이 `data/replay_notation.json` 으로 불러올 때만 적용한다.
