### 확인 필요 (내용 문제 — 교열로 고치지 않음)
- n3-016 결과: "건전성 측면 영향은 작으나 흐름 건전성 저하" — 한 항목 안에서 '건전성 영향이 작다'와 '건전성 저하'가 맞부딪침. 어떤 건전성(설비·흐름)을 뜻하는지 원문 확인 필요
- n3-027 결과: "일부는 물과 격렬히 반응하여 발열·압력 상승 가능" — 주어 '일부'가 무엇(혼입된 다른 물질? NH3?)인지 불분명. NH3라면 물에 녹으며 발열하나 '격렬히 반응'은 과한 서술일 수 있음. 원문 확인 필요
- n3-002 원인·권고: "수격(급격한 밸브 조작)으로 인한 순간 과대 유량" — 수격은 급격한 밸브 조작의 결과인데 괄호로 둘을 같은 것처럼 적음. 같은 행 권고 "과류방지밸브(엑세스플로우밸브)"의 외래어 표기(excess flow → 익세스)도 확인 필요
