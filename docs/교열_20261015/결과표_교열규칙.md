## 0. 이 글의 장르 — 먼저 읽을 것

HAZOP 워크시트 칸은 **개조식(짧은 명사구·명사형 종결)** 이 정상이다. 논문 문단처럼 풀어 쓰지 않는다.
목표는 "현장 안전 담당자가 소리 내어 읽었을 때 걸리지 않는 개조식 문장"이다. 자연스러운 항목은 **손대지 않는다**(과교정 금지). 바꾼 건수가 많다고 좋은 교열이 아니다.

## 1. 규칙

| # | 규칙 | 예 (전 → 후) |
|---|---|---|
| R1 | **종결 통일 — 모든 칸은 명사형 종결.** "~한다/~된다/~흐른다/~이다." 같은 서술형 종결과 끝의 마침표를 없앤다. 명사구("~ 역류", "~ 상승")나 "~음/~함/~됨"으로 끝낸다. 한 행 안에서 섞지 않는다 | "LPG가 역류한다" → "LPG가 역류함" / "~ 과소하게 흐른다" → "~보다 적게 흐름" |
| R2 | **기호 통일.** 'A/B'가 '또는·및'을 뜻하면 가운뎃점(·)이나 '또는'으로 쓴다. "화재/폭발" → "화재·폭발". 단위(m³/h, kg/cm²)와 고유 표기(ON/OFF)는 그대로 둔다. 범위는 물결표(~) | "압력 상실/대기압 수준" → "압력 상실 또는 대기압 수준" |
| R3 | **번역투 '~에 의한/~에 의해'** 는 "~로", "~ 때문에 생긴"으로 푼다. '~로 인한'·'~에 따른'은 개조식 관용이라 한 항목에 두 번 이상 겹칠 때만 정리한다 | "외부 가열·화재 노출에 의한 내압 상승" → "외부 가열·화재 노출로 내압 상승" |
| R4 | **어색한 한자어·조어**를 우리말로 바꾼다: 타 → 다른, 장시간화 → 길어짐, 미형성 → 형성되지 않음, 기 설치 → 이미 설치된. 표준 공학 용어(체절 운전, 플래싱, 베이퍼록, 수격, 퍼지, 인터록, 라인업)는 그대로 둔다 | "하역 장시간화" → "하역 시간이 길어짐" |
| R5 | **명사 연쇄 해체.** 조사 없이 명사가 네 개 이상 이어져 읽히지 않으면 조사·어미를 넣어 푼다 | "누출 수반 저압 조기 식별을 위한 가스감지기 배치" → "누출로 압력이 떨어지는 것을 일찍 알 수 있도록 가스감지기 배치" |
| R6 | **영어 단어.** 표준 약어(LPG, NH3, ESV, ESD, BLEVE, LOTO, ERC, NPSH, PTW, HAZOP, STS, SIL, PSV)는 그대로 둔다. 일반 영어 낱말이 단독으로 쓰였으면 우리말을 앞세우고 영어는 괄호에 둔다(이미 괄호 병기면 그대로) | "~ 공정으로 carryover" → "~ 공정으로 액이 딸려 넘어감(carryover)" |
| R7 | **조사·호응·띄어쓰기.** 주술 호응이 깨진 곳, 목적어가 빠진 곳(Part D 유형 3), 맞춤법·띄어쓰기 오류를 고친다. 로마자 뒤 조사는 붙인다("LPG 가" → "LPG가") | "설계 의도인 LPG가 아닌 다른 물질" → "설계에서 정한 LPG가 아닌 다른 물질" |
| R8 | **과장·단정어**(Part C)를 낮춘다. 단, 위험성평가의 결과 칸에서 "화재·폭발", "대형 사고" 같은 결과 서술은 과장이 아니다 | — |

## 2. 절대 하지 말 것

1. **수치·단위·물질명·설비명·약어를 바꾸지 않는다.** 교정 전후 숫자는 1:1로 같아야 한다.
2. **원인·결과·권고의 내용을 보태거나 빼지 않는다.** 항목을 합치거나 나누지 않는다(항목 수 불변).
3. **사실관계가 틀려 보여도 고치지 않는다.** 예: 긴급차단밸브를 ESD로 적은 곳(ESV와 다름), 물질 성질 오류 → 표의 '확인 필요' 목록에만 적는다.
4. 가이드워드(No·More·Less·Reverse·Part of·As well as·Other than·Too early 등)와 파라미터 이름은 손대지 않는다.

## 3. 산출물 형식 (반드시 이대로)

파일 하나, 노드마다 아래 두 절.

```markdown
## {노드 ID} — {노드 이름}
- 검토한 행 n개 · 바꾼 항목 n개 · 확인 필요 n개

| 행 id | 칸 | AS-IS (원문 그대로) | TO-BE | 규칙 |
|---|---|---|---|---|
| i1-003 | 이탈 | 탱크로리 인수→압축기→저장탱크 이송 경로에서 LPG 하역·충전 유량이 설계 의도보다 과소하게 흐른다 | 탱크로리 인수→압축기→저장탱크 이송 경로에서 LPG 하역·충전 유량이 설계 의도보다 적음 | R1·R4 |

### 확인 필요 (내용 문제 — 교열로 고치지 않음)
- i1-008 권고: "긴급차단밸브(ESD)" — 긴급차단밸브의 약어는 ESV, ESD는 긴급정지계통. 원문 확인 필요
```

- **바꾼 항목만** 적는다. 바꾸지 않은 항목은 적지 않는다.
- AS-IS는 추출 파일의 문장을 **한 글자도 바꾸지 않고** 복사한다(나중에 찾아 바꾸기로 반영한다).
- 같은 문장이 같은 노드 여러 행에 그대로 나오면 한 줄로 쓰고 '행 id' 칸에 id를 모두 쓴다(쉼표 구분).
- 칸 이름: 이탈 / 원인 / 결과 / 기존 안전장치 / 권고 / 시나리오 연계 / 필요한 정보.
- 표 안의 `|` 문자는 `\|`로 쓴다.
