| 항목 | 값 |
|---|---|
| 접속 방식 | AWS **IAM Identity Center** Access Portal `https://d-9267fcca7f.awsapps.com/start` |
| 계정명 | `korea-kiro-dominiklee01` (AWS Account #327784329358, IdentityStoreId d-9267fcca7f) |
| 리전 안내 | **us-west-2** |
| 비밀번호 | 8/25 재설정 완료 메일 수신됨 (`no-reply@signin.aws`) |

이 구조에서 핵심 질문은 하나다. **Access Portal에 로그인했을 때 "AWS accounts" 탭에 계정 타일(권한 세트)이 보이는가.** 보이면 Kiro뿐 아니라 그 계정의 Bedrock을 SSO 자격증명으로 쓸 수 있고, 안 보이면 사무국이 Kiro 앱 접근만 열어 둔 것이라 별도 요청이 필요하다. 지금까지 이 확인이 이루어졌다는 기록이 폴더에 없다.

확인 절차(10분):

```bash
aws configure sso
#   SSO start URL : https://d-9267fcca7f.awsapps.com/start
#   SSO region    : us-west-2   (안 되면 us-east-1)
#   → 브라우저 로그인 후 계정/권한세트 선택 화면이 뜨면 성공, 프로파일명 예: kiro-contest
aws sso login --profile kiro-contest
PYTHONIOENCODING=utf-8 .venv/Scripts/python.exe tools/check_bedrock_access.py --region us-west-2
```

`aws configure sso` 단계에서 "No AWS accounts are available to you"가 뜨면 → 경로 (2)로.
