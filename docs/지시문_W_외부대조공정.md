# 지시문 W — 실측 사례 재생에 외부 공개 HAZOP 대조 공정 추가 (FR-10, 10/8 사용자 결정)

배경: 재생 화면의 예시 공정 2개(LPG 출하·염소)가 "골드셋 없음"으로 떠 사용자가 원치 않음(10/8). 사용자 선택 = "공개 LPG 공정 추가".

| # | 요구 | 수용 기준 |
|---|---|---|
| W-1 | 새 공정 `lpg_iocl` "LPG 충전소 (공개 HAZOP 대조)" — 인도 IOCL 충전소 공개 HAZOP(2014) 노드 4개를 노드 입력(직접 서술, 안전장치는 비움 — NH3 골드 노드와 같은 조건)으로 | 카탈로그 시험 |
| W-2 | 대조 기준 `data/reference/iocl_lpg_2014.json` — 워크시트의 (가이드워드, 파라미터) 쌍만. High→More, Low→Less, "Less / No"→Less(보수적). 가이드워드 칸이 빈 4항목(Start-up/shut down·Maintenance·Corrosion/Erosion·Drawing Errors)은 제외 | 쌍만 있고 문장 없음(시험) |
| W-3 | `split: "external"` — recall 은 기존 규칙(`tools/_replay.py`) 그대로, **NH3 골드셋 표·홀드아웃 합계와 섞지 않는다** | 시험 |
| W-4 | 화면: 파란 배지 "공개 HAZOP 대조 · 외부 팀 작성", 요약 줄 "외부 공개 HAZOP 대비 recall", 정확도 줄에 **쉬운 기준이라는 고지**(공정변수 점검표 11행 — 모델 기본 축과 겹침) | AppTest |
| W-5 | 기존 예시 공정 문구: "골드셋 없음" → "정성 검토용"(대조 기준 없음) | AppTest |

## 고지 (화면·README 에 그대로)

- 골드셋이 아니다. 외부 팀이 다른 설비에 대해 쓴 워크시트이고 우리 노드 입력은 그 설명을 옮겨 쓴 것이다.
- 4노드 모두 같은 공정변수 점검표 11행이라 recall 이 후하게 나온다. NH3 골드셋(설비·절차형 파라미터 다수)과 같은 난이도가 아니다.
- 염소 예시는 공개 워크시트가 없어 그대로 "정성 검토용"이다.
