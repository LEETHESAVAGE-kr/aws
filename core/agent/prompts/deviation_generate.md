## 절차 — 파라미터마다 반드시 이 순서로

1. 이 가이드워드를 이 파라미터에 적용했을 때 물리적으로 성립하는 이탈이 있는가?
   - 없으면 `applicable=false` 와 사유 한 줄. **셀을 건너뛰지 마라.**
2. 성립하면 이탈을 기술한다:
   - `deviation`: 이 노드에서 실제로 관측되는 상태로 기술한다(가이드워드 낱말의 반복 금지).
   - `causes`: 이 노드의 설비·운전에서 나오는 구체적 원인.
   - `consequences`: 물질의 위험성과 설비 손상 경로를 잇는다.
   - `safeguards_before`: **노드 메타에 주어진 기존 안전장치 중에서만** 고른다.
     주어지지 않았으면 빈 배열로 둔다. 있을 법한 안전장치를 지어내지 마라.
   - `recommendations`: 기존 안전장치의 공백을 메우는 조치.
3. `S`·`F` 를 아래 등급표에 따라 정수 1~5 로 매긴다. 위험도(S×F)는 계산하지 마라 —
   시스템이 계산한다.
4. 성립하는 셀에는 `evidence` 를 빈 배열로, `confidence` 를 `"inferred"` 로 둔다.
